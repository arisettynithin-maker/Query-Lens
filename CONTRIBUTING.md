# Contributing to QueryLens

Thanks for contributing.

## Setup
1. Install dependencies:
```bash
npm install
```
2. Start local dev:
```bash
npm run dev
```

## Quality Checks
Run before opening a PR:
```bash
npm run lint
npm run typecheck
npm run build
```

## Coding Style
- TypeScript-first, strongly typed APIs.
- Keep changes modular and artifact-aware.
- Prefer concise UI copy and consistent product terminology.

## Pull Requests
- Describe the problem and your solution clearly.
- Include screenshots for visible UI changes.
- Keep PR scope focused and production-ready.
